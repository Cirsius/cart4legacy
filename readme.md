## cart4legacy

back port of modern cartpvp behavior to bukkit 1.14-1.21.3 servers

### fixes
- `crossbow-carting`: (1.14-1.21.3) arrows fired from crossbows ignite when they pass through fire or lava
- `tnt-minecart-drops`: (1.14-1.18.2) makes destroyed carts drop a tnt minecart instead of tnt and a minecart
